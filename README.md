# Pass Data App
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 12). It demonstrates passing data (name and email) between two activities using Intent extras.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Input fields for name and email
- Sends data to the second activity
- Displays received data on the second screen
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully transfers the user's name and email from the first screen to the second screen using Intent extras.
